Diferença entre meus cursos

Como as duas formações se complementam na minha jornada.

Análise e Desenv. de Sistemas (AMS)

Status: Formada em Fevereiro/2026.

Foco: Este curso me deu a base pesada de lógica de programação. O foco do ADS é mais amplo, envolvendo modelagem de banco de dados, engenharia de software e desenvolvimento de sistemas robustos, como o sistema LUMENSYS que criei.

Sistemas para Internet

Status: Cursando atualmente.

Foco: É muito mais direcionado para a web. Aqui o foco é nas interfaces, experiência do usuário (UX/UI), criação de conteúdo e aplicações que rodam diretamente no navegador, unindo programação ao design visual.
